# 未来年表 | Future Time Line

**2030〜2050年の社会や暮らしを、559件の未来シナリオから探索するSharePointアプリです。**

年度・カテゴリ・キーワードで未来を探し、詳細画面で変化のポイントや生活者の視点を読めます。お気に入り・評価・ポイントはユーザーごとにSharePointへ保存します。

![HOME画面：年度・カテゴリで絞り込み、画像付きシナリオを閲覧](./docs/images/home.png)

※キャプチャは以前の画面で、現在の表示とは一部異なります。

## 主な機能・使い方

- **探す**：2030・2035・2040・2045・2050年、カテゴリ、キーワード、お気に入りで絞り込み。空白区切りの検索はAND検索です。
- **読む**：カード／横長リストを切り替えて閲覧。リスト表示では概要抜粋も表示します。詳細では変化の前後、背景、関連する生活者シナリオ（全3,304件）を確認できます。
- **保存する**：ハートでお気に入りを登録・解除。保存失敗時は通知から再試行できます。
- **評価する**：詳細下部の「このシナリオを評価」から3問すべてに回答し、「評価する」で保存。初回評価でシナリオ1件につき合計1ptを獲得します。評価済みの回答は編集できますが、再加点はありません。
- **表示を変える**：ライト／ダークテーマとスマートフォン表示に対応。テーマ選択はブラウザーに保存します。ヘッダー右端にはプロフィール写真とポイント数を表示します。

## 開発・ビルド

SPFx 1.23.2、React 17、TypeScript、Fluent UI 8を使用しています。Node.jsは **22.14以上・23未満** が必要です。

```bash
npm install
npm run start
```

[config/serve.json](./config/serve.json) に設定したSharePointの `FTLApp.aspx` を開きます。開発ポートは `4321` です。同じポートのサーバーは停止してください。初回は開発用HTTPS証明書の信頼が必要になる場合があります。

ページとWebパーツは自動作成しません。SharePoint側でページを用意し、デバッグスクリプトの読み込みを許可して、編集画面から `FTLApp` を追加・保存してください。閲覧モードではアプリを全画面表示するため、専用ページで使用します。

本番パッケージは開発サーバーを停止してから生成します。

```bash
npm run build
```

生成される `sharepoint/solution/sp-fx-ftl-app.sppkg` をアプリカタログへ配置してください。

## SharePointリストの設定

保存先URLは現在の実装で固定されています。表示名は変更できますが、URLは維持してください。列は下記の英字名で作成します。

### ユーザー管理（List2）

URL：`/sites/-TMC-/Lists/List2` ／推奨表示名：**未来年表ユーザ管理**

| 列 | 種類・設定 |
|---|---|
| Title | 標準の1行テキスト（表示名） |
| UserKey | 1行テキスト・必須（ログイン名） |
| FavoritesJson | 複数行テキスト・プレーンテキスト・変更の追加なし |
| Points | 数値・小数点以下0桁・既定値0（ポイント残高） |
| EvaluationPoints | 数値・小数点以下0桁・既定値0（評価による付与済み件数） |

初回アクセスで本人の行を作成します。既存行の未設定ポイントは0に初期化します。旧ブラウザー保存のお気に入りは、本人の行がなかった場合に移行できます。共有ブラウザーでは自分のデータか確認してください。

### シナリオ評価（List3）

URL：`/sites/-TMC-/Lists/List3` ／表示名：**未来年表シナリオ評価**

| 列 | 種類・設定 |
|---|---|
| Title | 標準の1行テキスト（シナリオID） |
| UserKey | 1行テキスト（ログイン名） |
| ScenarioId | 1行テキスト |
| WillHappen | 数値・小数点以下0桁 |
| LifeImpact | 数値・小数点以下0桁 |
| WantItCome | 数値・小数点以下0桁 |
| EvaluationKey | 1行テキスト・一意の値を強制しない |

| 質問 | 保存列 | ポジティブ（`1`） | ネガティブ（`-1`） |
|---|---|---|---|
| 本当にくる？ | WillHappen | きそう | こない |
| 生活はかわる？ | LifeImpact | かわる | かわらない |
| 来たらうれしい？ | WantItCome | 来てほしい | 来てほしくない |

評価行と評価キーは送信時にアプリが作成します。事前の行作成は不要です。`Points` と `EvaluationPoints` は**List2だけ**に必要です。

### 権限・運用上の注意

- 両リストとも、詳細設定で読み取り・作成／編集を**本人が作成したアイテムのみ**に制限してください。管理権限を持つユーザーは例外です。
- 一意制約はアイテムレベル権限と併用しないでください。評価リストでは利用者のアイテム削除権限も外してください。
- 複数端末からの同時初回登録では重複行ができる可能性があります。検出時は自動統合せず、管理者への確認を促します。
- 評価件数と `EvaluationPoints` を照合し、未反映分だけ `Points` に加算します。評価保存とポイント更新は別リクエストで、反映失敗時は評価の再読み込みで再照合します。
- 評価行を管理者が削除する場合は、ポイント情報との整合にも注意してください。本人によるリスト直接編集を防ぐサーバー側の不正対策は未実装です。

## データ・画像の更新

Python 3の標準ライブラリーでExcelと画像からデータを生成します。元ファイルは変更しません。更新後は再ビルドしてください。

```bash
python3 scripts/import-scenarios.py "/path/to/未来シナリオ検証用.xlsx" "/path/to/MS_Dummy"
```

画像だけを差し替える場合（macOS、`MS00001_image.png` 形式）：

```bash
python3 scripts/replace-scenario-images.py "/path/to/未来シナリオ画像検証用"
```

シナリオ本文・画像はパッケージに含まれ、アプリを読み込める利用者へ配信されます。
